# Acceptance checklist

- [ ] Fresh install starts without runtime errors.
- [ ] Empty state clearly guides the learner.
- [ ] Create, reload, edit subject metadata and delete a subject.
- [ ] Create concept, practice it, reveal source/reference and save rating.
- [ ] Due concepts are recommended before future-due concepts.
- [ ] Poor rating shortens interval and increments lapse count.
- [ ] Export and restore JSON round-trip all supported data.
- [ ] Invalid JSON produces a clear error.
- [ ] Import errors are shown in plain language.
- [ ] Source excerpt is retained for imported concepts.
- [ ] Keyboard-only navigation works.
- [ ] Reduced-motion preference is respected.
- [ ] At narrow viewport there is no horizontal overflow.
- [ ] PWA install/offline behavior checked on target browsers.
- [ ] No credentials or personal study data are present in repository.
